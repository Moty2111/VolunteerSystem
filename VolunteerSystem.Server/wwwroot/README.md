# wwwroot

Папка для статических файлов, которые отдаёт сам сервер (ASP.NET Core).

Сейчас клиент работает через собственный dev-сервер Vite (`npm run dev`,
адрес `https://localhost:61000`), поэтому папка пустая — это нормально и
предупреждение `The WebRootPath was not found` больше не появляется.

Если понадобится запускать приложение без Vite (один процесс, один порт):

1. Соберите клиент: `npm run build` в папке `volunteersystem.client`
2. Скопируйте содержимое `dist` в эту папку
3. Запустите сервер — он отдаст собранное SPA по `http://localhost:5084`
